# Platter для Windows

Десктопный клиент Subsonic в том же оформлении, что и Android-приложение. Compose Multiplatform
Desktop, воспроизведение через libvlc. Это отдельная сборка Gradle: мобильное приложение в `../app`
не затрагивается.

## Что нужно

- JDK 21 (для сборки)
- 64-битный [VLC](https://www.videolan.org/vlc/) на машине, где собирается установщик: из него берётся libvlc.
  В установщик попадают только `libvlc.dll`, `libvlccore.dll` и плагины для звука (без видео, интерфейса и Lua,
  около 40 МБ), поэтому тем, кто ставит Platter, VLC не нужен. Другой VLC: `-PvlcHome=<папка>` или `VLC_HOME`.
  При запуске из исходников (`./gradlew run`) используется та же копия; не нашлась встроенная, берётся VLC из системы

## Запуск и сборка

```
./gradlew run                  # запустить из исходников
./gradlew test                 # тесты (плеер идёт через настоящий libvlc с пустым аудиовыходом)
./gradlew createDistributable  # build/compose/binaries/main/app/Platter/Platter.exe
./gradlew packageMsi           # установщик build/compose/binaries/main/msi/Platter-<версия>.msi; нужен WiX Toolset 3
```

Журнал ошибок пишется в `%APPDATA%\Platter\logs\platter.log` (необработанные исключения, всё из stderr, сбои
плеера; пароль и токен в адресах замазываются) и `vlc.log` (ошибки самого libvlc). Каждый файл не больше 1 МБ,
предыдущий лежит рядом как `*.1.log`.

Тесты по пути `build/screenshots` складывают PNG с экранами, нарисованными на фейковом сервере.

## Что есть

- **Вход, главная, библиотека, поиск, страницы альбома, артиста и плейлиста**, плеер с очередью,
  лайки, скроблинг, пробел для паузы.
- **«Назад» и «Вперёд» возвращают страницу туда, где её оставили:** прокрутка запоминается по месту в цепочке
  страниц (`ui/PageScroll.kt`), страница, открытая заново, начинается сверху. Новый список на странице берёт
  `rememberPageListState` / `rememberPageGridState` / `rememberPageScrollState` вместо обычных `remember…State`.
- **Поиск как на телефоне.** Ранжирование результатов (точное совпадение выше префикса, префикс выше
  слова, звёздочки и прослушанное поднимают), «лучший результат» карточкой, исправление раскладки
  («tkrf» → «елка»), транслита («Elka»), ё/е, опечаток по именам из библиотеки, слитного написания и
  одного неверного слова во фразе. Недавние запросы запоминаются по Enter или когда открыт результат.
  Код перенесён из `app/.../helper/search` и покрыт тестами.
- **Меню трека** (правая кнопка или «⋯»): играть радио, добавить похожие, дальше, в очередь, в плейлист,
  убрать из плейлиста, выше/ниже, оценить звёздами, к альбому и артисту, поделиться (ссылка в буфер),
  информация о треке.
- **Плеер:** в плейлист, меню «⋯».
- **Страница артиста:** популярные песни, радио, лайк артиста, альбомы по годам, «Фанаты также слушают»,
  биография с ссылкой на Last.fm.
- **Главная** с теми же разделами и умолчаниями, что в Android: «Для вас», любимые песни, альбомы и
  артисты, Flashback по десятилетиям, новинки, недавно добавленное и проигранное, закреплённые плейлисты,
  «Показать все» у лент. Порядок и видимость разделов меняются кнопкой «Arrange home».
- **Плейлисты:** создать, добавить, убрать, переместить, переименовать, удалить, закрепить на главной.
  Длинные списки уходят пачками по 100 песен, чтобы прокси не отвергал запрос.
- **Библиотека:** альбомы, артисты, плейлисты, жанры; фильтр и сортировка; «Liked Songs».
- **Настройки:** выход, пересканирование библиотеки, качество потока и формат транскодирования,
  ReplayGain (при следующем запуске; по умолчанию «Track»), кроссфейд (включён по умолчанию; не применяется между подряд идущими треками одного альбома), скроблинг. My Wave включается сам, только если сервер — music.timoha.top; адреса для него в настройках нет.
- **My Wave и тексты песен**, в том числе поиск по словам из текстов.
- **Очередь на сервере** (Настройки → Sync play queue). Очередь и место в ней сохраняются через
  `savePlayQueue` (по индексу, формой POST и окном вокруг играющей песни там, где сервер этого не умеет, чтобы
  запрос не упирался в лимит прокси), при закрытии окна тоже. При запуске Platter предлагает продолжить с
  места, где остановились на телефоне, плашкой «Pick up where you left off». Выключено по умолчанию, как на телефоне.
- **Подкасты:** вкладка в библиотеке, страница канала с эпизодами, добавить по адресу ленты, обновить,
  скачать эпизод на сервере, удалить; новые эпизоды можно вывести на главную.
- **Интернет-радио:** станции с сервера, добавить, изменить, удалить; в плеере вместо полосы «LIVE».
  Подкасты и радио не скроблятся и не попадают в сохранённую очередь.
- **Прослушивание, не дошедшее до сервера, не теряется:** засчитанное прослушивание записывается в
  `%APPDATA%\Platter\pending-scrobbles.json` и уходит, когда сервер отвечает (при старте и раз в минуту), по порядку.
- **Домашний адрес сервера** (Настройки → Connection): пока он отвечает, Platter ходит на него, дома и
  вне дома без переключений вручную; проверка раз в полминуты и когда трек не загрузился.

- **Офлайн-загрузки** (экран Downloads в боковой панели). Песня, альбом, плейлист или все любимые скачиваются
  на диск в папку `Исполнитель/Альбом/NN - Название.ext` (папку выбирают в Настройках, по умолчанию
  `%APPDATA%/Platter/Downloads`): оригинал через `download` или, если задано ограничение битрейта,
  перекодировка сервером. Две загрузки одновременно, прогресс, отмена и повтор; пока идёт запись, файл
  называется `.part`, поэтому оборванная загрузка не выглядит целой. Скачанная песня играет с диска, а без
  сервера работают и экран Downloads (он строится из индекса и сохранённых обложек), и воспроизведение, и
  очередь непереданных прослушиваний.
- **Умные загрузки** (выключены по умолчанию): песни сохраняются, пока их слушают; когда лимит (25-500)
  исчерпан, уступают место те, что слушали давнее всех. Скачанное вручную или хранимое ради лайка в счёт не идёт
  и не удаляется. **Хранить любимые**: каждая песня с сердцем скачана, а копия, сделанная ради лайка, исчезает
  вместе с ним; скачанное вручную остаётся.
- **Deezer через Deemix plus** (как в мобильном приложении): раздел «Get from Deezer» под результатами поиска
  (артисты лентой по числу фанатов, треки с отметкой «In your library», альбомы), страницы артиста и альбома из
  публичного каталога Deezer, скачивание трека, альбома или всего артиста с подтверждением и остатком дневной
  квоты, предпрослушивание 30 секунд (музыка на паузе, пока играет превью). Адрес сайта ищется сам (хост сервера
  и порт 8088 дома, `deemix.<домен>` вне дома) или задаётся в Настройках; пароль сайта нужен, только если он
  отличается от пароля сервера, и хранится запечатанным DPAPI.
- **Эквалайзер** libvlc (кнопка в плеере и в Настройках): десять полос, предусиление, девять пресетов; применяется
  сразу, во время песни, и запоминается.
- **Язык интерфейса** (Настройки → Interface → Language), те же восемь, что в телефоне: English, Deutsch, Français,
  中文, 한국어, Português, Italiano, Русский; по умолчанию язык Windows. Выбор применяется сразу, без перезапуска, и
  запоминается (`language` в settings.json). Тексты в коде написаны по-английски и ищутся в словарях по самому
  английскому тексту (`i18n/I18n.kt`: `t("…")`, `tn(n, "%d song", "%d songs")` для множественного числа;
  словари — `i18n/Words*.kt`). Нового текста без перевода быть не может: `I18nTest` сверяет все `t("…")` из кода
  со всеми словарями, а также плейсхолдеры и числа. Названия песен, исполнителей и всё, что присылает сервер,
  не переводится.

- **Всё остаётся на месте после перезапуска.** В `settings.json`: ширины боковых панелей, открытая справа панель
  (текст песни или очередь), текст песни в полноэкранном плеере, страница, на которой закрыли приложение, и
  история переходов (кнопка «Назад» ведёт туда же), вкладка и сортировка библиотеки, фильтр загрузок
  (`choices`, ключи вида `library.tab`), размер, положение и «развёрнутость» окна (положение, которого уже нет
  ни на одном мониторе, отбрасывается; при развёрнутом окне обычный размер не теряется). В вертикальном окне высота текста в полноэкранном
  плеере тоже меняется: ручка над текстом (появляется под курсором), двойной щелчок возвращает исходную
  пропорцию, значение хранится как `wordsHeight`. Очередь воспроизведения
  с местом в песне, перемешиванием и повтором лежит рядом в `queue.json` (чужому аккаунту не показывается) и
  возвращается остановленной: по пробелу песня продолжается с того же места. Если включена «Очередь на
  сервере», берётся она, как и раньше.

- **Несколько серверов, как на телефоне.** Каждый сервер, на который вы входили, остаётся в списке
  (`servers` в settings.json: название, адрес, логин, домашний адрес, пароль под Windows DPAPI). «Выйти»
  завершает сессию, но сервер остаётся: на экране входа список, нажатие входит с сохранённым паролем,
  крестик убирает сервер, «Add a server» открывает форму. Тот же аккаунт при повторном входе обновляет
  запись, а не дублирует. Пока Timoha Premium нет среди серверов (с первого запуска), на экране входа над списком стоит его карточка:
  нажатие открывает короткую форму, только логин и пароль, адрес `music.timoha.top` подставляется сам.
  Домашний адрес у каждого сервера свой. Если пароль прочитать нельзя (другой
  пользователь Windows), форма открывается с заполненными адресом и логином. Кто уже был залогинен до
  этого, переносится в список сам.

Пароль не хранится открытым: сохраняются токен и соль (`t = md5(пароль + соль)`) в
`%APPDATA%\Platter\settings.json`; для My Wave пароль лежит там же, но запечатанный Windows DPAPI.

## Пока нет

«Your top songs» (на телефоне их считает локальная история прослушиваний), медиаклавиши, трей.

## Самообновление

Версия записана один раз, в `platterVersion` в `build.gradle.kts`: из неё берутся версия установщика и версия, с которой
приложение сверяется (`-Dplatter.version`; при запуске из исходников и в тестах её нет, и обновление не ищется).

`update/Updater.kt` читает список релизов `Timoha589/Platter` на GitHub и берёт самый новый (не черновик и не пре-релиз),
у которого есть файл `.msi` и версия выше текущей; число в теге выбирается регулярным выражением, так что подходят и `v1.0.1`,
и `desktop-v1.0.1`. При запуске (не чаще раза в сутки; «Позже» откладывает на день) и по кнопке **Настройки → О приложении →
Проверить обновления** показывается диалог с описанием релиза. «Обновить» скачивает `.msi` в `%APPDATA%\Platter\update`,
проверяет размер и SHA-256 (его GitHub отдаёт в поле `digest`), затем запускает скрипт `apply-update.ps1`: он ждёт закрытия
Platter, ставит MSI (`msiexec /i … /qb`, журнал в `install.log` рядом) и открывает Platter снова; сам Platter закрывается так же,
как по крестику.

Установщик ставит по-пользовательски (`perUserInstall`), поэтому администратор и запрос UAC не нужны, и с постоянным
`upgradeUuid` новая версия заменяет старую, а не встаёт рядом. **`upgradeUuid` менять нельзя**: иначе у уже установленных
Platter обновление превратится во вторую копию. Первый раз установщик запускается вручную. Как выпустить версию (одна нумерация на телефон и ПК, в релиз кладётся то, что менялось) — `BUILDING.md`, 3b.

## Значок и окно

Значок приложения — тот же, что у телефона (зелёная «пластинка»; для каждого размера нарисована отдельно, чтобы не мылилась на панели задач): `icons/platter.ico` для
установщика (подключён в `build.gradle.kts`, сам установщик пока не собирался), `src/main/resources/icons/platter.png`
для окна, панели задач, левого верхнего угла и экрана входа. Заголовок окна (название, свернуть, развернуть, закрыть)
красится в тёмно-серый цвет из палитры приложения через Windows DWM (`ui/TitleBar.kt`; нужна Windows 11, на старых систем остаётся
обычный), рамка окна остаётся родной: привязка к краям и растягивание работают как всегда. В настройках внизу — ссылка на
репозиторий `github.com/Timoha589/Platter`.

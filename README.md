**Platter** — нативный музыкальный клиент для Android с открытым исходным кодом для серверов Subsonic.
Это форк [Tempo](https://github.com/CappielloAntonio/tempo) Антонио Каппьелло, полностью перерисованный
по дизайн-системе Spotify, описанной в [DESIGN.md](DESIGN.md).

Движок воспроизведения, слой Subsonic API, офлайн-загрузки, поддержка Android Auto и Chromecast
остались от Tempo и работают как раньше. Изменилась только внешность.

## Что изменилось в оформлении

| Область | Изменение |
|---------|-----------|
| Палитра | Material You / динамические цвета убраны. Фиксированная палитра Spotify: холст `#000000`, поверхность `#121212`, карточки `#1F1F1F`, акцент `#1ED760` |
| Режим | Только тёмный. Выбор темы убран — в `DESIGN.md` тёмный холст назван фирменным |
| Шрифт | Inter по шкале Spotify: заголовки разделов 24sp/700, названия 14sp/600, метаданные 12sp/400, не больше 24sp |
| Форма | 6dp у каждой обложки и карточки, полностью скруглённые «таблетки» у каждой кнопки и чипа |
| Геометрия | Обложка альбома — квадрат со скруглением 6dp, фото артиста — круг; этот чередующийся ритм в DESIGN.md назван «ритмом геометрии». Форму задаёт сам view (`ShapeableImageView`), а не только трансформация Glide, поэтому при отсутствии обложки показывается заглушка правильной формы, а не квадрат |
| Ритм | Единая шкала отступов для всех лент: поля 16dp, 24dp над заголовком, 12dp под ним, 12dp между карточками, 32dp между разделами |
| Кнопки | Один залитый стиль: белая «таблетка» с чёрным текстом. Зелёный зарезервирован за воспроизведением и перемешиванием; вторичное действие рядом — «таблетка» с контуром |
| Нижняя панель | Чёрная, во всю ширину, 58dp, без индикатора активной вкладки — текущую вкладку отмечают белая иконка и более жирная подпись |
| Страница артиста | Круглый портрет целиком на градиентной шапке, имя и роль по центру под ним; когда шапка прокручивается, имя переезжает на панель инструментов |
| Плеер | Белая круглая кнопка воспроизведения, белый прогресс на стальной дорожке, белые однолинейные значки управления |
| Брендинг | Новый знак (зелёная виниловая пластинка), значки приложения, заставка и название |

Дизайн-токены лежат в [`app/src/main/res/values/spotify_tokens.xml`](app/src/main/res/values/spotify_tokens.xml)
и являются единственным источником правды; `colors.xml` сопоставляет с ними цветовые роли Material 3,
поэтому около 90 существующих разметок получили новый вид без переписывания.

## Обновление

Platter обновляется сам, не выходя из приложения: при запуске и по кнопке
**Настройки → Проверить обновления** он смотрит последний [релиз на GitHub](https://github.com/Timoha589/Platter/releases/latest),
скачивает APK, сверяет контрольную сумму и передаёт его системному установщику Android. Первую
установку нужно сделать вручную, обновления дальше приходят сами. Как выпустить новую версию, описано в
[BUILDING.md](BUILDING.md).

## Сборка

Нужны JDK 17+ и Android SDK (платформа 35, build-tools 35.0.0).

```bash
./gradlew assemblePlatterDebug
```

APK появится в `app/build/outputs/apk/platter/debug/`. Релизные сборки, подпись и установка на
устройство описаны в [BUILDING.md](BUILDING.md).
